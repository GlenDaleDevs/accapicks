## Checklist: Information Needed for Applications

Most affiliate programs will ask for:

- [ ] Full legal name
- [ ] Date of birth
- [ ] Email address
- [ ] Phone number
- [ ] Physical address
- [ ] Website URL (https://accapicks.com)
- [ ] Website description
- [ ] Expected monthly traffic
- [ ] Target countries (UK, Ireland)
- [ ] Promotion methods (comparison site, social)
- [ ] Payment details (bank account or e-wallet)
- [ ] Tax ID (if applicable)
