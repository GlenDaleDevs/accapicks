NOTES
-----
- CSRF protection: FastAPI uses Bearer tokens (not cookies), so CSRF risk is minimal.
  Only a concern if we add cookie-based auth later.
- Accessibility (a11y): Important but can be incrementally improved post-launch.
  Focus on keyboard navigation and contrast ratios first.
- API versioning: Not needed for MVP with small user base. Add when breaking changes needed.
